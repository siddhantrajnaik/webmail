# IIT Delhi Webmail

A neubrutalist institutional email client for IIT Delhi, built with React + TypeScript + Vite.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- One-click IITD email configuration (IMAP/SMTP)
- Unified inbox with folder navigation
- Compose, reply, forward emails
- Offline support via Service Worker
- PWA installable on iOS/Android/Desktop
- Category-tagged emails (Course, Admin, Hostel, Research)

## Tech Stack

- React 18 + TypeScript + Vite
- Material Symbols icons
- vite-plugin-pwa (Workbox service worker)
- Tailwind CSS (via CDN in prototypes, native CSS in production)
